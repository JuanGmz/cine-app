# Cine App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an Expo mobile app that shows a movie billboard, movie detail and a simulated seat map, backed by the `noeavl/api-movies` API.

**Architecture:** Expo Router screens call TanStack Query hooks, which call a thin typed `fetch` client that unwraps the API's `{success,data,meta}` envelope. Seat occupancy, showtimes and totals are pure client-side logic in `src/lib/seats.ts`.

**Tech Stack:** Expo + Expo Router, TypeScript (strict), TanStack Query, Jest (`jest-expo`).

**Spec:** `docs/superpowers/specs/2026-11-09-cine-app-design.md`

## Global Constraints

- API base URL from `EXPO_PUBLIC_API_URL`, default `http://localhost:3000/api`.
- API envelope: `{ success, data, meta? }`; `meta = { page, limit, total, totalPages }`; `limit` max 100.
- Movie ids are UUID strings; `duration` is minutes; `rating` is 0–10; `synopsis`, `duration`, `posterUrl`, `rating` may be null/absent.
- Seat map: 8 rows × 10 columns, ≈25 % occupied, seeded by `movieId + showtime`; showtimes `16:00`, `18:30`, `21:00`; fixed price per seat.
- Dark cinema theme with gold accent. UI copy in Spanish.
- No auth, no persistence, no CRUD, no Directors/Categories tab.
- Commit messages carry no AI attribution lines.

## Review Focus

- Category with zero movies: its row is hidden, not rendered empty.
- Movie with null `posterUrl`/`duration`/`synopsis`/`rating`: renders placeholder / "Sin información", never "null" or "NaN".
- Search with no matches: shows the empty state, not blank screen.
- API unreachable or `success:false`: error view with "Reintentar", no crash.
- Unknown movie id (404): error state with a way back.
